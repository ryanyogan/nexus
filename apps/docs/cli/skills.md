# nexus skills

Browse and install skill templates.

## Usage

```bash
nexus skills <command> [options]
```

## Commands

| Command | Description |
|---------|-------------|
| `search <query>` | Search for skills |
| `list` | List available skills |
| `info <id>` | Get skill details |

## Examples

```bash
# Search for TypeScript skills
nexus skills search typescript

# List all skills
nexus skills list

# Get skill info
nexus skills info code-review
```

## Options

| Option | Description |
|--------|-------------|
| `--category <cat>` | Filter by category |
| `--limit <n>` | Max results |
