# Introduction

**Nexus is the missing brain in your AI workflow.**

Every time you start a new AI session, you lose context. You re-explain your project structure, remind the AI about your conventions, and watch your token budget evaporate on information you've provided a dozen times before.

Nexus fixes this. It gives your AI assistant persistent memory, instant access to up-to-date documentation, and a curated registry of MCP servers—all through a single MCP connection.

## Quick Start

Add Nexus to your AI client in 30 seconds:

<Terminal title="Add to Claude Code">
<Line prompt>claude mcp add nexus -- npx -y @anthropic-ai/mcp-remote https://mcp.nexus.yogan.dev/sse</Line>
<Line />
<Line><Check>Added MCP server nexus</Check></Line>
</Terminal>

Or add directly to your MCP config file:

```json title="Claude Desktop / Cursor / VS Code"
{
  "mcpServers": {
    "nexus": {
      "url": "https://mcp.nexus.yogan.dev/sse"
    }
  }
}
```

That's it. Your AI now has access to documentation search, persistent memory, and the MCP server registry.

:::tip Ready to dive in?
Head to the [Installation Guide](/getting-started/installation) for detailed setup instructions, or jump straight to the [CLI Quickstart](/getting-started/cli-quickstart) to set up your editors automatically.
:::

## Features at a Glance

### Documentation Tools

| Tool | Description |
|---------|-------------|
| **resolve-library** | Find library IDs for documentation queries |
| **query-docs** | Search indexed documentation with semantic search |
| **get-library-info** | Get detailed library metadata and stats |
| **list-libraries** | Browse all indexed documentation |

### Memory Tools

| Tool | Description |
|---------|-------------|
| **save-memory** | Store project context, decisions, and learnings |
| **recall-memories** | Retrieve relevant memories using natural language |
| **get-project-context** | Load all context for a specific project |
| **list-memories** | Browse and manage stored memories |

### Server Registry Tools

| Tool | Description |
|---------|-------------|
| **discover-servers** | Find MCP servers by capability or category |
| **get-server-info** | Get detailed server documentation |
| **get-server-config** | Generate ready-to-use MCP configurations |
