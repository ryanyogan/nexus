## Get Installation Config

After finding a server:

> "Give me the config to install the postgres MCP server"

<Terminal title="Installation config">
<Line><Text color="gray">→ AI calls</Text> <Text color="green">get-server-config</Text></Line>
<Line>   <Text color="gray">serverId:</Text> "postgres"</Line>
<Line>   <Text color="gray">format:</Text> "claude-desktop"</Line>
<Line />
<Line><Text color="cyan">Add this to your claude_desktop_config.json:</Text></Line>
</Terminal>

```json
{
  "mcpServers": {
    "postgres": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-postgres"],
      "env": {
        "DATABASE_URL": "postgresql://user:pass@localhost:5432/db"
      }
    }
  }
}
```

## Adding Environment Variables

Most database servers need connection strings:

```json title="With environment variables"
{
  "mcpServers": {
    "postgres": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-postgres"],
      "env": {
        "DATABASE_URL": "postgresql://user:pass@localhost:5432/mydb"
      }
    }
  }
}
```

:::warning Keep secrets safe
Don't commit connection strings to git. Use environment variables or a secrets manager.
:::
