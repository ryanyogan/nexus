## Manual Setup

### Step 1: Create MCP Config File

Create or edit `.cursor/mcp.json` in your **home directory** for global config, or in your **project root** for project-specific config.

**Global config (recommended):**
```bash
# macOS/Linux
~/.cursor/mcp.json

# Windows
%USERPROFILE%\.cursor\mcp.json
```

**Project config:**
```bash
your-project/.cursor/mcp.json
```

### Step 2: Add Nexus Server

```json title=".cursor/mcp.json"
{
  "mcpServers": {
    "nexus": {
      "url": "https://mcp.nexus.yogan.dev/sse"
    }
  }
}
```

### Step 3: Restart Cursor

Cursor will automatically detect the new MCP server on restart.

## Verify It Works

In Cursor's chat, ask:

> "What Nexus tools do you have access to?"

You should see tools like:
- `resolve-library`
- `query-docs`
- `save-memory`
- `recall-memories`
- `discover-servers`

## Using Local Server (Alternative)

For offline development or custom setups:

```json title=".cursor/mcp.json"
{
  "mcpServers": {
    "nexus": {
      "command": "npx",
      "args": ["-y", "@nexus/cli", "serve"]
    }
  }
}
```

---

## Project vs Global Config

| Scope | Location | Use Case |
|-------|----------|----------|
| Global | `~/.cursor/mcp.json` | Same servers for all projects |
| Project | `./. cursor/mcp.json` | Project-specific servers |

Project config overrides global config for that project.

---

## Troubleshooting

### Server not showing up

1. Ensure the file is valid JSON (no trailing commas)
2. Check file location is correct
3. Restart Cursor completely

### Connection errors

Try the local server alternative if you're behind a firewall:

```json
{
  "mcpServers": {
    "nexus": {
      "command": "npx",
      "args": ["-y", "@nexus/cli", "serve"]
    }
  }
}
```

### Multiple MCP servers

You can add Nexus alongside other servers:

```json
{
  "mcpServers": {
    "nexus": {
      "url": "https://mcp.nexus.yogan.dev/sse"
    },
    "other-server": {
      "command": "npx",
      "args": ["-y", "other-mcp-server"]
    }
  }
}
```
