# Installation

Nexus works as an MCP (Model Context Protocol) server. You can connect to the hosted version instantly, or run it locally for full control.

## Fastest Setup (30 Seconds)

Use the CLI to automatically configure your editors:

<Terminal title="One-command setup">
<Line prompt>npx @nexus/cli init</Line>
<Line />
<Line><Star><Text color="cyan" bold>Welcome to Nexus!</Text></Star></Line>
<Line><Text color="gray">The AI Documentation & Skills Hub</Text></Line>
<Line />
<Line><Text bold>Select your editors:</Text> <Text color="gray">(Space to toggle, Enter to confirm)</Text></Line>
<Line><Text color="green">  ✓ Claude Code</Text></Line>
<Line><Text color="green">  ✓ Cursor</Text></Line>
<Line />
<Line><Check><Text color="green">Setup complete! Configured 2 editor(s).</Text></Check></Line>
</Terminal>

That's it! The CLI handles everything automatically.

## Manual Configuration

If you prefer manual setup, add the Nexus MCP server to your client config.

### Server URL

```
https://mcp.nexus.yogan.dev/sse
```

### Claude Code

The fastest way for Claude Code users:

<Terminal title="Add to Claude Code">
<Line prompt>claude mcp add nexus -- npx -y @anthropic-ai/mcp-remote https://mcp.nexus.yogan.dev/sse</Line>
<Line />
<Line><Check>Added MCP server nexus</Check></Line>
</Terminal>

### Claude Desktop

Edit your Claude Desktop configuration file:

| OS | Path |
|-------|------|
| macOS | `~/Library/Application Support/Claude/claude_desktop_config.json` |
| Windows | `%APPDATA%\Claude\claude_desktop_config.json` |
| Linux | `~/.config/Claude/claude_desktop_config.json` |

```json title="claude_desktop_config.json"
{
  "mcpServers": {
    "nexus": {
      "url": "https://mcp.nexus.yogan.dev/sse"
    }
  }
}
```

Restart Claude Desktop to apply changes.

### Cursor

Create or edit `.cursor/mcp.json` in your project root or home directory:

```json title=".cursor/mcp.json"
{
  "mcpServers": {
    "nexus": {
      "url": "https://mcp.nexus.yogan.dev/sse"
    }
  }
}
```

Cursor will automatically detect and connect to the server.

### VS Code

VS Code requires an MCP extension. We recommend the [MCP Extension](https://marketplace.visualstudio.com/items?itemName=anthropic.mcp).

Add to your VS Code settings:

```json title="settings.json"
{
  "mcp.servers": {
    "nexus": {
      "url": "https://mcp.nexus.yogan.dev/sse"
    }
  }
}
```

### OpenCode

Create `mcp.json` in your project root:

```json title="mcp.json"
{
  "mcpServers": {
    "nexus": {
      "url": "https://mcp.nexus.yogan.dev/sse"
    }
  }
}
```

### Zed

Add to your Zed settings (`~/.config/zed/settings.json`):

```json title="settings.json"
{
  "context_servers": {
    "nexus": {
      "url": "https://mcp.nexus.yogan.dev/sse"
    }
  }
}
```

## Local Server (CLI)

For offline access or development, run Nexus locally:

<Terminal title="Local server setup">
<Line prompt>npm install -g @nexus/cli</Line>
<Line />
<Line prompt>nexus init</Line>
<Line><Check>Configuration complete</Check></Line>
<Line />
<Line prompt>nexus serve</Line>
<Line><Text color="cyan" bold>Nexus MCP Server</Text></Line>
<Line><Check>Server ready (stdio mode)</Check></Line>
</Terminal>

Then update your client configuration to use the local server:

```json title="Local server configuration"
{
  "mcpServers": {
    "nexus": {
      "command": "nexus",
      "args": ["serve"]
    }
  }
}
```

:::info When to use local mode
- **Offline development** — No internet required
- **Custom libraries** — Index your own documentation
- **Privacy** — Keep memory and queries local
- **Development** — Contributing to Nexus itself
:::

## Authentication (Optional)

Most Nexus features work without authentication. To enable memory persistence and higher rate limits, authenticate via the CLI:

<Terminal title="Authenticate">
<Line prompt>nexus auth login</Line>
<Line />
<Line><Text color="cyan">Opening browser for authentication...</Text></Line>
<Line />
<Line><Check><Text color="green">Successfully authenticated as user@example.com</Text></Check></Line>
</Terminal>

This opens a browser for OAuth authentication. Your credentials are stored securely and used automatically by both the CLI and MCP server.

## Verify Installation

After configuring your client, verify Nexus is working:

<StepList>
  <Step title="Ask your AI about available tools">
    "What Nexus tools do you have access to?"
    
    You should see tools like `resolve-library`, `query-docs`, `recall-memories`, and `discover-servers`.
  </Step>
  <Step title="Test documentation search">
    "Search the React documentation for useEffect cleanup patterns"
    
    Your AI should use `resolve-library` and `query-docs` to find relevant results.
  </Step>
  <Step title="Test the server registry">
    "Find MCP servers for database access"
    
    Your AI should use `discover-servers` to find PostgreSQL, SQLite, and other database servers.
  </Step>
</StepList>

If you see responses using Nexus tools, you're all set!

## Troubleshooting

### Connection refused

Ensure the URL is correct: `https://mcp.nexus.yogan.dev/sse`

Check that your firewall allows outbound HTTPS connections.

### Tools not appearing

Restart your AI client after configuration changes. Some clients cache MCP connections.

### Rate limited

Authenticate with `nexus auth login` to increase rate limits.

### SSE not supported

Some clients don't support SSE (Server-Sent Events). Use the local CLI server instead:

```json
{
  "mcpServers": {
    "nexus": {
      "command": "npx",
      "args": ["-y", "@nexus/cli", "serve"]
    }
  }
}
```
