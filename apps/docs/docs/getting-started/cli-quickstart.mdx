# CLI Quickstart

The Nexus CLI is the fastest way to get started. Run one command and your editors are configured automatically.

## Install the CLI

<Line />
<Line prompt>nexus --version</Line>
<Line>@nexus/cli 1.0.0</Line>
</Terminal>

## Local MCP Server

Run Nexus as a local MCP server for offline access:

<Terminal title="Start Local Server">
<Line prompt>nexus serve</Line>
<Line />
<Line><Text color="cyan" bold>Nexus MCP Server</Text></Line>
<Line><Text color="gray">Mode: stdio</Text></Line>
<Line><Text color="gray">Version: 1.0.0</Text></Line>
<Line />
<Line><Check>Server ready</Check></Line>
<Line><Text color="gray">Waiting for MCP client connection...</Text></Line>
</Terminal>

Configure your AI client to use the local server:

```json title="claude_desktop_config.json"
{
  "mcpServers": {
    "nexus": {
      "command": "nexus",
      "args": ["serve"]
    }
  }
}
```

:::info When to use local mode
- **Offline development** — No internet required
- **Custom libraries** — Index your own documentation
- **Privacy** — Keep memory and queries local
- **Development** — Contributing to Nexus itself
:::

## Command Reference

| Command | Description |
|---------|-------------|
| `nexus init` | Interactive setup wizard |
| `nexus serve` | Start local MCP server |
| `nexus docs search <query>` | Find libraries by name |
| `nexus docs query <lib> <query>` | Search library documentation |
| `nexus docs list` | List indexed libraries |
| `nexus memory save` | Store a new memory |
| `nexus memory search <query>` | Semantic search memories |
| `nexus memory list` | List recent memories |
| `nexus memory context` | Get project context |
| `nexus servers search <query>` | Find MCP servers |
| `nexus servers list` | List all servers |
| `nexus servers info <id>` | Server details |
| `nexus servers config <id>` | Generate install config |
| `nexus auth login` | Authenticate |
| `nexus auth logout` | Clear credentials |
| `nexus stats` | View usage statistics |

:::info Getting help
Run `nexus --help` or `nexus <command> --help` for detailed usage information.
:::
