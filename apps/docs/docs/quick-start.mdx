# Quick Start

Get Nexus running in 30 seconds.

<QuickStart title="Fastest Setup">
Run this command to automatically configure your editors:

```bash
npx @nexus/cli init
```

Select your editors, and you're done!
</QuickStart>

---

## What Just Happened?

The CLI automatically:

1. **Detected your installed editors** (Claude Code, Cursor, VS Code, etc.)
2. **Added the Nexus MCP server** to each editor's config
3. **Verified the connection** works

Your AI assistant now has access to:

- **Documentation search** across 50+ libraries
- **Persistent memory** for project context
- **MCP server registry** for discovering tools

---

## Try It Out

Open your AI client and try these prompts:

### Search Documentation

> "Search the Next.js documentation for App Router middleware patterns"

<Terminal title="What happens behind the scenes">
<Line><Text color="gray">→ AI calls</Text> <Text color="green">resolve-library</Text> <Text color="gray">to find "nextjs"</Text></Line>
<Line><Text color="gray">→ AI calls</Text> <Text color="green">query-docs</Text> <Text color="gray">with the query</Text></Line>
<Line><Text color="gray">→ Returns relevant code examples and explanations</Text></Line>
</Terminal>

### Save Project Context

> "Remember that this project uses TypeScript, Hono for the API, and deploys to Cloudflare Workers"

<Terminal title="Memory saved">
<Line><Text color="gray">→ AI calls</Text> <Text color="green">save-memory</Text></Line>
<Line><Text color="gray">→ Context is stored and can be recalled in future sessions</Text></Line>
</Terminal>

### Find MCP Servers

> "I need to connect to a PostgreSQL database. Find me an MCP server for that."

<Terminal title="Server discovery">
<Line><Text color="gray">→ AI calls</Text> <Text color="green">discover-servers</Text> <Text color="gray">with query "postgresql"</Text></Line>
<Line><Text color="gray">→ Returns the postgres MCP server with installation config</Text></Line>
</Terminal>

## Available Tools

Your AI now has these tools available:

| Tool | What it does |
|------|--------------|
| `resolve-library` | Find library IDs for doc queries |
| `query-docs` | Search documentation semantically |
| `save-memory` | Store project context and decisions |
| `recall-memories` | Find relevant memories |
| `get-project-context` | Load all context for a project |
| `discover-servers` | Find MCP servers by capability |
| `get-server-config` | Get installation configs |
