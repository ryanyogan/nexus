## Adding Authentication

For authenticated access (required for memory features):

```json
{
  "mcpServers": {
    "nexus": {
      "url": "https://api.nexus.yogan.dev/mcp",
      "headers": {
        "Authorization": "Bearer YOUR_API_KEY"
      }
    }
  }
}
```

Get your API key from [nexus.yogan.dev/dashboard/keys](https://nexus.yogan.dev/dashboard/keys).

:::caution[Keep Keys Secure]
Don't commit config files with API keys to version control. Use environment variables where possible.
:::

## Environment Variables

Some clients support environment variable substitution:

```json
{
  "mcpServers": {
    "nexus": {
      "url": "https://api.nexus.yogan.dev/mcp",
      "headers": {
        "Authorization": "Bearer ${NEXUS_API_KEY}"
      }
    }
  }
}
```

Set in your shell profile:

```bash
export NEXUS_API_KEY="nx_sk_your_key_here"
```

## Multiple Servers

You can configure multiple MCP servers:

```json
{
  "mcpServers": {
    "nexus": {
      "url": "https://api.nexus.yogan.dev/mcp"
    },
    "postgres": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-postgres"],
      "env": {
        "POSTGRES_CONNECTION_STRING": "postgresql://..."
      }
    },
    "filesystem": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-filesystem", "/path/to/dir"]
    }
  }
}
```

## Troubleshooting Setup

### Verify Connection

Ask your AI assistant:

> "Can you use the Nexus MCP tools? Try listing some libraries."

If working, you'll see a response with library data.

### Common Issues

**"MCP server not found"**
- Check the config file location
- Verify JSON syntax (no trailing commas)
- Restart the AI assistant

**"Connection refused"**
- Check your internet connection
- Verify firewall settings
- Try the URL in a browser: `https://api.nexus.yogan.dev/health`

**"Unauthorized"**
- Check your API key is valid
- Ensure the header format is correct
- Regenerate key if needed

### Debug Mode

Some clients support verbose logging:

```json
{
  "mcpServers": {
    "nexus": {
      "url": "https://api.nexus.yogan.dev/mcp"
    }
  },
  "debug": true
}
```

## Advanced Configuration

### Timeout Settings

```json
{
  "mcpServers": {
    "nexus": {
      "url": "https://api.nexus.yogan.dev/mcp",
      "timeout": 30000
    }
  }
}
```

### Retry Configuration

```json
{
  "mcpServers": {
    "nexus": {
      "url": "https://api.nexus.yogan.dev/mcp",
      "retry": {
        "maxRetries": 3,
        "backoff": "exponential"
      }
    }
  }
}
```

   > "Recall memories about testing"

   > "Search for documentation on a library called 'nonexistentlib123'"
   
   Should return a helpful "not found" message.
