The Nexus SDK provides a TypeScript/JavaScript interface for interacting with Nexus programmatically. Use it to search documentation, manage memories, and integrate Nexus into your applications.

## Quick Start

```typescript
import { NexusClient } from '@nexus/sdk'

const nexus = new NexusClient({
  baseUrl: 'https://api.nexus.yogan.dev'
})

// Search for a library
const libraries = await nexus.libraries.search('hono')

// Query documentation
const results = await nexus.libraries.queryDocs({
  libraryId: 'hono',
  query: 'How to create middleware?'
})
```

## Documentation Search

### Search Libraries

Find libraries by name:

```typescript
const libraries = await nexus.libraries.search('react')

// Returns array of matching libraries
// [{ id: 'react', name: 'React', description: '...' }, ...]
```

### Query Documentation

Search within a library's documentation:

```typescript
const results = await nexus.libraries.queryDocs({
  libraryId: 'hono',
  query: 'How to handle form data?',
  limit: 5
})

// Returns relevant documentation chunks
for (const result of results) {
  console.log(result.title)
  console.log(result.content)
  console.log(result.relevanceScore)
}
```

### Get Library Info

Get detailed information about a library:

```typescript
const info = await nexus.libraries.getInfo('react')

console.log(info.name)        // "React"
console.log(info.version)     // "18.2.0"
console.log(info.description) // "A JavaScript library for building user interfaces"
console.log(info.chunkCount)  // 1234
```

### List Libraries

List all available libraries:

```typescript
const libraries = await nexus.libraries.list({
  category: 'frontend',
  limit: 20
})
```

## Memory Management

### Save Memory

Store project context, decisions, or session summaries:

```typescript
await nexus.memories.save({
  title: 'Project Architecture',
  content: 'This is a pnpm monorepo with TanStack Start...',
  type: 'project_context',
  project: 'nexus',
  tags: ['architecture', 'cloudflare'],
  importance: 8
})
```

### Recall Memories

Search across stored memories:

```typescript
const memories = await nexus.memories.recall({
  query: 'database architecture',
  project: 'nexus',
  limit: 5
})
```

### Get Project Context

Retrieve all context for a project:

```typescript
const context = await nexus.memories.getProjectContext({
  project: 'nexus',
  includeTypes: ['project_context', 'decision']
})
```

### List Memories

Browse stored memories:

```typescript
const memories = await nexus.memories.list({
  project: 'nexus',
  type: 'decision',
  limit: 20
})
```

### Update Memory

Modify an existing memory:

```typescript
await nexus.memories.update({
  memoryId: 'mem_123',
  content: 'Updated content...',
  importance: 9
})
```

### Delete Memory

Remove a memory:

```typescript
await nexus.memories.delete('mem_123')
```

## Server Discovery

### Discover Servers

Find MCP servers by capability:

```typescript
const servers = await nexus.servers.discover({
  query: 'database',
  category: 'database',
  limit: 10
})
```

### Get Server Info

Get details about a specific server:

```typescript
const server = await nexus.servers.getInfo('postgres')

console.log(server.name)
console.log(server.tools)
console.log(server.installInstructions)
```

### Get Server Config

Generate installation configuration:

```typescript
const config = await nexus.servers.getConfig({
  serverId: 'postgres',
  format: 'claude-desktop'
})

console.log(config)
// { mcpServers: { postgres: { ... } } }
```

## Error Handling

The SDK throws typed errors for different failure scenarios:

```typescript
import { NexusClient, NexusError, NotFoundError, RateLimitError } from '@nexus/sdk'

try {
  const results = await nexus.libraries.queryDocs({
    libraryId: 'nonexistent',
    query: 'test'
  })
} catch (error) {
  if (error instanceof NotFoundError) {
    console.log('Library not found')
  } else if (error instanceof RateLimitError) {
    console.log('Rate limited, retry after:', error.retryAfter)
  } else if (error instanceof NexusError) {
    console.log('Nexus error:', error.message)
  }
}
```

## TypeScript Support

The SDK is written in TypeScript and provides full type definitions:

```typescript
import type {
  Library,
  LibraryInfo,
  QueryResult,
  Memory,
  MemoryType,
  Server,
  ServerConfig
} from '@nexus/sdk'

// All methods return typed responses
const library: LibraryInfo = await nexus.libraries.getInfo('react')
const memories: Memory[] = await nexus.memories.list({ project: 'nexus' })
```

## Configuration Options

```typescript
const nexus = new NexusClient({
  // Base URL for the Nexus API
  baseUrl: 'https://api.nexus.yogan.dev',
  
  // Optional API key for authenticated endpoints
  apiKey: 'your-api-key',
  
  // Request timeout in milliseconds (default: 30000)
  timeout: 30000,
  
  // Retry configuration
  retry: {
    maxRetries: 3,
    retryDelay: 1000
  }
})
```
