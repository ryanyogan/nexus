## Overview

Help expand the Nexus library catalog by submitting documentation sources for indexing. We accept GitHub repositories, documentation websites, and OpenAPI specifications.

## What Can Be Submitted

| Source Type | Description | Example |
|-------------|-------------|---------|
| GitHub Repo | Repository with docs/ or README | github.com/user/repo |
| Documentation Site | Official docs website | docs.example.com |
| OpenAPI Spec | API specification file | api.example.com/openapi.json |

## Submission Process

### 1. Prepare Your Submission

Before submitting, ensure:

- The library has public documentation
- You have the URL to the docs source
- The library is actively maintained

### 2. Submit via Web UI

1. Go to [nexus.yogan.dev/submit](https://nexus.yogan.dev/submit)
2. Fill in the library details:
   - **Library Name** - Official name (e.g., "React", "Hono")
   - **Source URL** - GitHub repo or docs site
   - **Description** - Brief description (optional)
   - **Email** - For status updates (optional)
3. Click Submit

### 3. Submit via API

```bash
curl -X POST "https://api.nexus.yogan.dev/api/submissions" \
  -H "Content-Type: application/json" \
  -d '{
    "libraryName": "awesome-lib",
    "sourceUrl": "https://github.com/user/awesome-lib",
    "description": "A library for doing awesome things"
  }'
```

### 4. Review Process

Submissions are reviewed for:

- **Quality** - Documentation is comprehensive
- **Relevance** - Useful to the developer community
- **Accessibility** - Docs are publicly accessible
- **Freshness** - Library is actively maintained

### 5. Status Updates

Track your submission status:

| Status | Description |
|--------|-------------|
| `pending` | Awaiting review |
| `approved` | Approved, queued for indexing |
| `indexing` | Currently being indexed |
| `indexed` | Complete and searchable |
| `rejected` | Not accepted (see reason) |

Check status at `/api/submissions/{id}` or watch for email updates.

## Guidelines

:::tip[Submission Guidelines]
**Do submit:**
- Popular open-source libraries
- Well-documented frameworks
- Official API documentation
- Actively maintained projects

**Don't submit:**
- Personal/private projects
- Abandoned repositories
- Paywalled documentation
- Duplicate libraries
:::

## Rejection Reasons

Common reasons for rejection:

- **Insufficient docs** - Not enough documentation to index
- **Duplicate** - Library already indexed
- **Private** - Documentation is not publicly accessible
- **Inactive** - No updates in over 2 years
- **Quality** - Documentation doesn't meet quality standards

## After Indexing

Once indexed, the library will:

1. Appear in the Explore page
2. Be searchable via MCP tools
3. Be available via REST API

Indexing typically takes 1-24 hours depending on documentation size.
