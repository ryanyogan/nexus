## Overview

The Mobile Terminal feature lets you access your development environment from your phone or tablet. Perfect for quick fixes on the go or monitoring your dev server.

## Getting Started

### 1. Start the Tunnel

From your development machine, start the Nexus tunnel:

```bash
npx nexus tunnel
```

You'll receive a unique URL like:

```
https://abc123.nexus.yogan.dev/terminal
```

### 2. Connect from Mobile

Open the URL on your mobile device. You'll see a full terminal interface.

### 3. Authenticate

Sign in with your Nexus account to access the terminal.

## Keyboard Shortcuts

The mobile terminal supports touch gestures:

| Gesture | Action |
|---------|--------|
| Two-finger tap | Send Ctrl+C |
| Swipe up | Scroll history |
| Swipe down | Scroll history |
| Long press | Paste from clipboard |
| Pinch | Zoom text size |

## Security

- All connections are encrypted via TLS
- Sessions require Nexus authentication
- Tunnels automatically expire after 24 hours of inactivity
- You can revoke tunnel access anytime

:::caution[Security Notice]
The mobile terminal provides full shell access to your machine. Only use it on trusted networks and always sign out when done.
:::

## Use Cases

- **Quick fixes** - Fix a typo without opening your laptop
- **Monitoring** - Watch logs and server output on the go
- **Code review** - Review git diffs from your phone
- **Deployments** - Trigger deployments while away from desk

## Limitations

- Limited screen real estate on phones
- No graphical applications
- Clipboard sync requires HTTPS
- Some terminal features may not work perfectly
