## Common Issues

### MCP Connection Issues

#### "Failed to connect to MCP server"

**Cause:** Your AI assistant can't reach the Nexus server.

**Solutions:**
1. Check your internet connection
2. Verify the server URL is correct: `https://api.nexus.yogan.dev/mcp`
3. Ensure your firewall isn't blocking the connection
4. Try restarting your AI assistant

#### "Invalid MCP configuration"

**Cause:** The MCP config file has syntax errors.

**Solutions:**
1. Validate your JSON syntax
2. Ensure the config file is in the correct location
3. Check for trailing commas or missing brackets

```json
// Correct format
{
  "mcpServers": {
    "nexus": {
      "url": "https://api.nexus.yogan.dev/mcp"
    }
  }
}
```

### Search Issues

#### "Library not found"

**Cause:** The library isn't indexed or the name doesn't match.

**Solutions:**
1. Use `resolve-library` to search for the correct name
2. Try alternative names (e.g., "nextjs" vs "next.js")
3. Check if the library is indexed at [nexus.yogan.dev/explore](https://nexus.yogan.dev/explore)
4. [Submit the library](/submit) for indexing if not available

#### "No results for query"

**Cause:** The query is too broad or doesn't match indexed content.

**Solutions:**
1. Be more specific in your query
2. Use different terminology
3. Try breaking down complex questions
4. Check if the feature exists in the library's docs

### Memory Issues

#### "Memory not saving"

**Cause:** Authentication or rate limit issues.

**Solutions:**
1. Ensure you're signed in to Nexus
2. Check if you've hit the memory limit (Free: 5, Pro: unlimited)
3. Verify the project name is consistent

#### "Can't recall memories"

**Cause:** No memories match the query or wrong project.

**Solutions:**
1. Use exact project name when recalling
2. Try broader search terms
3. Use `list-memories` to see what's stored
4. Check memory type filters

### Rate Limiting

#### "Too many requests"

**Cause:** You've exceeded the rate limit.

**Solutions:**
1. Wait for the rate limit to reset (usually 1 minute)
2. Upgrade to Pro for higher limits
3. Optimize your queries to reduce requests
4. Cache results where possible

Rate limits:
- Documentation: 30 requests/minute
- Memory: 20 requests/minute
- General: 100 requests/minute

### Authentication Issues

#### "Unauthorized" errors

**Cause:** Invalid or expired authentication.

**Solutions:**
1. Sign out and sign back in
2. Regenerate your API key
3. Check the API key hasn't expired
4. Verify the Authorization header format

```bash
# Correct format
Authorization: Bearer nx_sk_your_key_here
```

## Getting Help

If you're still having issues:

1. **Check the status page** - [status.nexus.yogan.dev](https://status.nexus.yogan.dev)
2. **Search GitHub Issues** - [github.com/ryanyogan/nexus/issues](https://github.com/ryanyogan/nexus/issues)
3. **Ask on Discord** - Join our community for help
4. **Email support** - support@nexus.yogan.dev (Pro users)

## Reporting Bugs

When reporting a bug, include:

- Your AI assistant and version
- The MCP config you're using
- Steps to reproduce the issue
- Any error messages
- Expected vs actual behavior
