## Your API Keys, Encrypted

The Secrets Vault provides secure, encrypted storage for your API keys and credentials. Store keys once and access them securely across all your Nexus-connected tools.

All secrets are encrypted using **AES-256-GCM** encryption before storage. Only you can decrypt your secrets.

## Managing Secrets

### Adding a Secret

1. Go to [Settings > Secrets](https://nexus.yogan.dev/settings/secrets)
2. Click "Add Secret"
3. Enter a name (e.g., "OpenAI Production")
4. Paste your API key
5. Click "Save"

### Using Secrets

Once stored, secrets can be referenced by name in your tools:

```json
{
  "openai_key": "$secrets.openai-production"
}
```

### Rotating a Secret

1. Go to Settings > Secrets
2. Click the rotate icon next to the secret
3. Enter the new key value
4. Click "Rotate"

The old key is immediately invalidated.

## API Access

List your secrets (names only, not values):

```bash
curl "https://api.nexus.yogan.dev/api/user/secrets" \
  -H "Authorization: Bearer <token>"
```

Add a new secret:

```bash
curl -X POST "https://api.nexus.yogan.dev/api/user/secrets" \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{"name": "openai-key", "value": "sk-..."}'
```

Retrieve a secret (requires explicit decrypt flag):

```bash
curl "https://api.nexus.yogan.dev/api/user/secrets/openai-key?decrypt=true" \
  -H "Authorization: Bearer <token>"
```

Rotate a secret:

```bash
curl -X PUT "https://api.nexus.yogan.dev/api/user/secrets/openai-key" \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{"value": "sk-new-key-..."}'
```

## Best Practices

:::caution[Security Best Practices]
1. **Use descriptive names** - e.g., "openai-production" not "key1"
2. **Rotate keys every 90 days** - Set calendar reminders
3. **Use separate keys for environments** - Dev, staging, production
4. **Review access logs regularly** - Check for unauthorized access
5. **Delete unused secrets** - Reduce your attack surface
:::
