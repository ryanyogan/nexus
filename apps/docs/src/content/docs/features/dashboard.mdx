## API Keys

API keys allow programmatic access to Nexus from your applications.

### Creating an API Key

1. Go to [Dashboard > API Keys](https://nexus.yogan.dev/dashboard/keys)
2. Click "Create New Key"
3. Enter a name for the key (e.g., "Production App")
4. Copy the generated key - it won't be shown again!

### Using API Keys

Include your API key in the Authorization header:

```bash
curl "https://api.nexus.yogan.dev/api/libraries" \
  -H "Authorization: Bearer nx_sk_your_api_key_here"
```

:::caution[Keep Keys Secret]
- Never commit API keys to version control
- Use environment variables in your applications
- Rotate keys immediately if compromised
:::
