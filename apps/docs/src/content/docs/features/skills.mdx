## What are AI Skills?

AI Skills are curated instruction sets that encode expert knowledge into reusable patterns. They help AI assistants perform specialized tasks like code review, documentation generation, test writing, and more with consistent quality.

Think of skills as expert playbooks - they capture the knowledge and best practices of experienced developers and make them available to any AI assistant.

## Skill Types

| Type | Description | Examples |
|------|-------------|----------|
| `analysis` | Examine and evaluate code | Code review, security audit, performance analysis |
| `generation` | Create new content | Test generation, documentation, boilerplate |
| `transformation` | Convert or refactor | Code migration, format conversion, refactoring |
| `integration` | Connect systems | API integration, database setup, CI/CD |
| `utility` | General helpers | Debugging, logging, error handling |

## Using Skills

To load a skill, ask your AI assistant:

```
Load the code-review skill from Nexus
```

The assistant will fetch the skill instructions and apply them to your task:

```
Using the code-review skill, review this function:

function processData(data) {
  // ... your code
}
```

## API Access

List available skills:

```bash
curl "https://api.nexus.yogan.dev/api/skills"
```

Get skill details:

```bash
curl "https://api.nexus.yogan.dev/api/skills/code-review"
```

Filter by type:

```bash
curl "https://api.nexus.yogan.dev/api/skills?type=analysis"
```

Search skills:

```bash
curl "https://api.nexus.yogan.dev/api/skills?search=react"
```
