## List Skills

List available AI skills with optional filtering.

```http
GET /api/skills
```

### Query Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `type` | string | Filter by type: `analysis`, `generation`, `transformation`, `integration`, `utility` |
| `search` | string | Search by name or description |
| `limit` | number | Results per page (default: 20) |
| `offset` | number | Pagination offset |

### Response

```json
{
  "success": true,
  "skills": [
    {
      "id": "code-review",
      "name": "Code Review",
      "description": "Expert code review with best practices",
      "type": "analysis",
      "author": "nexus",
      "version": "1.0.0",
      "usageCount": 5000
    }
  ],
  "pagination": {
    "total": 25,
    "limit": 20,
    "offset": 0
  }
}
```

## Get Skill

Get detailed information about a specific skill.

```http
GET /api/skills/:id
```

### Path Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `id` | string | Skill ID |

### Response

```json
{
  "success": true,
  "skill": {
    "id": "code-review",
    "name": "Code Review",
    "description": "Expert code review with security, performance, and maintainability analysis",
    "type": "analysis",
    "author": "nexus",
    "version": "1.0.0",
    "content": "## Code Review Skill\n\nWhen reviewing code, analyze for:\n\n1. **Security Issues**...",
    "usageCount": 5000,
    "rating": 4.8,
    "tags": ["security", "performance", "best-practices"]
  }
}
```

## Get Skill Content

Get just the skill content/instructions.

```http
GET /api/skills/:id/content
```

### Response

```text
## Code Review Skill

When reviewing code, analyze for:

1. **Security Issues**
   - SQL injection vulnerabilities
   - XSS vulnerabilities
   - Authentication/authorization flaws

2. **Performance**
   - N+1 queries
   - Unnecessary re-renders
   - Memory leaks

3. **Maintainability**
   - Code duplication
   - Complex conditionals
   - Missing error handling
```

## Examples

### List Analysis Skills

```bash
curl "https://api.nexus.yogan.dev/api/skills?type=analysis"
```

### Search Skills

```bash
curl "https://api.nexus.yogan.dev/api/skills?search=react"
```

### Get Skill Details

```bash
curl "https://api.nexus.yogan.dev/api/skills/code-review"
```

### Get Skill Content

```bash
curl "https://api.nexus.yogan.dev/api/skills/code-review/content"
```
