## Global Statistics

Get aggregate statistics about the Nexus platform.

```http
GET /api/stats
```

### Response

```json
{
  "success": true,
  "stats": {
    "libraries": {
      "total": 150,
      "indexed": 145,
      "pending": 3,
      "indexing": 2
    },
    "documentation": {
      "totalChunks": 125000,
      "totalTokens": 45000000
    },
    "usage": {
      "totalQueries": 500000,
      "totalChunkHits": 2500000
    }
  }
}
```

### Response Fields

| Field | Description |
|-------|-------------|
| `libraries.total` | Total libraries in the system |
| `libraries.indexed` | Libraries with complete documentation |
| `libraries.pending` | Libraries waiting to be indexed |
| `libraries.indexing` | Libraries currently being indexed |
| `documentation.totalChunks` | Total searchable documentation chunks |
| `documentation.totalTokens` | Total tokens across all documentation |
| `usage.totalQueries` | Total search queries made |
| `usage.totalChunkHits` | Total chunks returned in results |

## Popular Libraries

Get the most queried libraries.

```http
GET /api/stats/popular
```

### Query Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `limit` | number | Max results (default: 10, max: 50) |

### Response

```json
{
  "success": true,
  "libraries": [
    {
      "id": "react",
      "name": "React",
      "queryCount": 25000,
      "avgRelevanceScore": 0.87
    },
    {
      "id": "nextjs",
      "name": "Next.js",
      "queryCount": 18000,
      "avgRelevanceScore": 0.85
    },
    {
      "id": "hono",
      "name": "Hono",
      "queryCount": 12000,
      "avgRelevanceScore": 0.89
    }
  ]
}
```

## Recently Indexed

Get the most recently indexed libraries.

```http
GET /api/stats/recent
```

### Query Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `limit` | number | Max results (default: 10, max: 50) |

### Response

```json
{
  "success": true,
  "libraries": [
    {
      "id": "drizzle-orm",
      "name": "Drizzle ORM",
      "indexedAt": "2024-01-15T10:30:00Z",
      "chunkCount": 890
    },
    {
      "id": "tanstack-start",
      "name": "TanStack Start",
      "indexedAt": "2024-01-14T15:45:00Z",
      "chunkCount": 650
    }
  ]
}
```

## Examples

### Get Platform Stats

```bash
curl "https://api.nexus.yogan.dev/api/stats"
```

### Get Top 20 Popular Libraries

```bash
curl "https://api.nexus.yogan.dev/api/stats/popular?limit=20"
```

### Get Recent Additions

```bash
curl "https://api.nexus.yogan.dev/api/stats/recent?limit=5"
```
