## Submit Library

Submit a new library for indexing.

```http
POST /api/submissions
```

### Request Body

```json
{
  "libraryName": "awesome-lib",
  "sourceUrl": "https://github.com/user/awesome-lib",
  "description": "A great library for doing awesome things",
  "email": "user@example.com"
}
```

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `libraryName` | string | Yes | Name of the library |
| `sourceUrl` | string | Yes | GitHub repo or documentation URL |
| `description` | string | No | Brief description |
| `email` | string | No | Contact email for updates |

### Response

```json
{
  "success": true,
  "submission": {
    "id": "sub_abc123",
    "libraryName": "awesome-lib",
    "status": "pending",
    "createdAt": "2024-01-15T10:00:00Z"
  }
}
```

:::caution[Duplicate Submissions]
If a library has already been submitted, you'll receive a 409 Conflict response with the existing submission ID.
:::

## List Submissions

List all library submissions with optional filtering.

```http
GET /api/submissions
```

### Query Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `status` | string | Filter by status: `pending`, `approved`, `indexed`, `rejected` |
| `limit` | number | Results per page (default: 20) |
| `offset` | number | Pagination offset |

### Response

```json
{
  "success": true,
  "submissions": [
    {
      "id": "sub_abc123",
      "libraryName": "awesome-lib",
      "sourceUrl": "https://github.com/user/awesome-lib",
      "status": "pending",
      "createdAt": "2024-01-15T10:00:00Z"
    }
  ],
  "pagination": {
    "total": 50,
    "limit": 20,
    "offset": 0
  }
}
```

## Get Submission Status

Get the status of a specific submission.

```http
GET /api/submissions/:id
```

### Path Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `id` | string | Submission ID |

### Response

```json
{
  "success": true,
  "submission": {
    "id": "sub_abc123",
    "libraryName": "awesome-lib",
    "sourceUrl": "https://github.com/user/awesome-lib",
    "description": "A great library for doing awesome things",
    "status": "approved",
    "statusMessage": "Library approved for indexing",
    "createdAt": "2024-01-15T10:00:00Z",
    "updatedAt": "2024-01-15T12:00:00Z",
    "libraryId": "awesome-lib"
  }
}
```

### Status Values

| Status | Description |
|--------|-------------|
| `pending` | Awaiting review |
| `approved` | Approved, queued for indexing |
| `indexed` | Successfully indexed and searchable |
| `rejected` | Rejected (see statusMessage for reason) |

## Examples

### Submit a Library

```bash
curl -X POST "https://api.nexus.yogan.dev/api/submissions" \
  -H "Content-Type: application/json" \
  -d '{
    "libraryName": "my-awesome-lib",
    "sourceUrl": "https://github.com/user/my-awesome-lib",
    "description": "A library for awesome things"
  }'
```

### Check Submission Status

```bash
curl "https://api.nexus.yogan.dev/api/submissions/sub_abc123"
```

### List Pending Submissions

```bash
curl "https://api.nexus.yogan.dev/api/submissions?status=pending"
```
