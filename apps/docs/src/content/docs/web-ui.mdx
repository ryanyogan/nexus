## Overview

The Nexus web interface at [nexus.yogan.dev](https://nexus.yogan.dev) provides a visual way to explore indexed libraries, search documentation, and manage your account.

## Explore Page

The Explore page lets you browse all indexed libraries:

- **Search** - Find libraries by name
- **Filter by category** - Frontend, backend, database, etc.
- **Sort** - By popularity, recently updated, or alphabetically
- **View details** - See library stats, version, and documentation coverage

Access it at [nexus.yogan.dev/explore](https://nexus.yogan.dev/explore).

## Library Details

Click on any library to see:

- **Overview** - Description, version, categories
- **Documentation Stats** - Chunk count, last indexed date
- **Usage Stats** - Query count, average relevance score
- **Source** - Link to GitHub or documentation site

## Searching Documentation

Use the search bar on the Explore page to search across all documentation:

1. Enter your query (e.g., "react hooks state management")
2. Select a specific library or search all
3. View results ranked by relevance

:::tip[Search Tips]
- Be specific: "useEffect cleanup function" is better than "hooks"
- Include the library name for faster results
- Use quotes for exact phrases
:::

## Dashboard

The dashboard (requires sign-in) shows:

- **Usage stats** - API calls this month
- **API keys** - Create and manage keys
- **Skills** - Installed AI skills
- **Billing** - Subscription management

## Submitting Libraries

To request a new library be indexed:

1. Go to the Submit page
2. Enter the library name and source URL
3. Add an optional description
4. Submit for review

Submissions are reviewed within 24-48 hours.

## Settings

Manage your account settings:

- **Profile** - Name, email, avatar
- **Secrets** - API key vault
- **Preferences** - Theme, notifications
- **Security** - Password, 2FA

## Mobile Support

The web UI is fully responsive and works on mobile devices:

- Touch-friendly navigation
- Responsive search
- Mobile-optimized tables
