## Description

Search for a library/package by name to get its Nexus-compatible library ID. Use this tool before `query-docs` to find the correct library ID.

Returns matching libraries with their IDs, descriptions, and documentation coverage stats.

## Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `libraryName` | string | Yes | The name of the library to search for (e.g., 'react', 'nextjs', 'hono') |
| `query` | string | No | Optional task or question to rank results by relevance |

## Response

Returns an array of matching libraries:

```json
{
  "success": true,
  "results": [
    {
      "id": "hono",
      "name": "Hono",
      "description": "Ultrafast web framework for the Edge",
      "version": "4.0.0",
      "chunkCount": 1234,
      "sourceReputation": "High",
      "benchmarkScore": 85
    }
  ]
}
```

### Response Fields

| Field | Type | Description |
|-------|------|-------------|
| `id` | string | The library ID to use with other tools |
| `name` | string | Display name of the library |
| `description` | string | Short description |
| `version` | string | Latest indexed version |
| `chunkCount` | number | Number of documentation chunks |
| `sourceReputation` | string | "High", "Medium", or "Low" |
| `benchmarkScore` | number | Quality score (0-100) |

## Examples

### Basic Search

```json title="Request"
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "tools/call",
  "params": {
    "name": "resolve-library",
    "arguments": {
      "libraryName": "react"
    }
  }
}
```

### Search with Context

When you have a specific task in mind, include it to get better-ranked results:

```json title="Request"
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "tools/call",
  "params": {
    "name": "resolve-library",
    "arguments": {
      "libraryName": "router",
      "query": "file-based routing for React"
    }
  }
}
```

### Multiple Results

When a search returns multiple matches:

```json title="Response"
{
  "success": true,
  "results": [
    {
      "id": "tanstack-router",
      "name": "TanStack Router",
      "description": "Type-safe router for React",
      "benchmarkScore": 92
    },
    {
      "id": "react-router",
      "name": "React Router",
      "description": "Declarative routing for React",
      "benchmarkScore": 88
    },
    {
      "id": "next-router",
      "name": "Next.js Router",
      "description": "File-system based router",
      "benchmarkScore": 85
    }
  ]
}
```

## Tips

:::tip[Use the query parameter]
When searching for common terms like "router" or "state", include the `query` parameter to describe what you're trying to do. This helps rank results by relevance.
:::

:::note[Call limit]
Don't call this tool more than 3 times per question. If you can't find what you need after 3 calls, use the best result you have.
:::

## Common Patterns

### Finding the Right Library

1. Start with the most specific name you know
2. If results are ambiguous, add context with the `query` parameter
3. Choose based on `benchmarkScore` and `sourceReputation`

### Handling No Results

If no results are found, try:
- Alternative names (e.g., "nextjs" vs "next.js")
- The full package name (e.g., "@tanstack/react-router")
- A more general term
