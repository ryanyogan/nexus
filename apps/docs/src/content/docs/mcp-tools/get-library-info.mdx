## Description

Get detailed information about a specific library including description, version, documentation coverage, and usage statistics.

## Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `libraryId` | string | Yes | The library ID (e.g., 'react', 'hono') |

## Response

```json
{
  "success": true,
  "library": {
    "libraryId": "react",
    "name": "React",
    "description": "A JavaScript library for building user interfaces",
    "version": "18.2.0",
    "categories": ["frontend", "ui"],
    "source": {
      "type": "github",
      "url": "https://github.com/facebook/react",
      "stars": 220000,
      "lastUpdated": "2024-01-15T10:00:00Z"
    },
    "documentation": {
      "status": "indexed",
      "chunkCount": 1234,
      "lastIndexed": "2024-01-10T08:30:00Z",
      "sourceUrl": "https://react.dev/reference"
    },
    "usage": {
      "totalQueries": 15000,
      "avgRelevanceScore": 0.85
    },
    "isFeatured": true
  }
}
```

### Response Fields

| Field | Type | Description |
|-------|------|-------------|
| `libraryId` | string | Unique identifier for the library |
| `name` | string | Display name |
| `description` | string | Short description of the library |
| `version` | string | Latest indexed version |
| `categories` | string[] | Category tags |
| `source` | object | Source repository information |
| `documentation` | object | Documentation indexing status |
| `usage` | object | Usage statistics |
| `isFeatured` | boolean | Whether the library is featured |

### Documentation Status Values

| Status | Description |
|--------|-------------|
| `indexed` | Documentation fully indexed and searchable |
| `indexing` | Currently being indexed |
| `pending` | Queued for indexing |
| `failed` | Indexing failed (check source URL) |

## Examples

### Basic Request

```json title="Request"
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "tools/call",
  "params": {
    "name": "get-library-info",
    "arguments": {
      "libraryId": "react"
    }
  }
}
```

### Error: Library Not Found

```json title="Error Response"
{
  "jsonrpc": "2.0",
  "id": 1,
  "error": {
    "code": -32603,
    "message": "Library \"unknownlib\" not found"
  }
}
```
